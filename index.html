How this study works

This application uses real 3D mesh intersections rather than 2D footprint projections. For each sampled receiving location, it casts a ray toward the calculated sun. Existing buildings and terrain are tested first; the proposal is then tested for additional obstruction.

Interpreting results

Blue: existing-condition shade. Coral: additional shade from the proposal where the existing condition was sunlit. Pale green: no obstruction. Sampled m² refer to horizontal projected area (not roof slope area).

Precision and data quality

Upload an accurate triangulated terrain surface and surveyed roof-form/context model for defensible work. OpenStreetMap geometry and the demonstration building model are illustrative. The analytical grid can be refined to 0.5 m, but this never improves the source geometry or alignment itself. A daylight average is calculated using regular local-time samples and excludes nighttime.

Model orientation

Models must use metres and Y-up, X=east, −Z=north. Detailed context and terrain meshes must be registered to the same local site origin. A proposed building file is automatically re-centred horizontally and set onto elevation zero; adjust its east/north/height/rotation fields. The app uses a fixed UTC−7 offset for Vancouver in 2026 and later.
